gpt-5.6-luna

A single HTTP endpoint for text generation and image synthesis. Send a prompt, optionally attach reference images, and receive text plus generated images.

Operational gpt-5.6-luna REST · JSON

Base URL

http://localhost:8000

All routes are prefixed with /api/v1.

Authentication

Every request must include an API key. Pass it in the X-API-Key header, or in the Authorization header with the Bearer scheme.

# X-API-Key header
curl http://localhost:8000/api/v1/model \
  -H "X-API-Key: YOUR_KEY"

# Bearer token
curl http://localhost:8000/api/v1/model \
  -H "Authorization: Bearer YOUR_KEY"
i
Requests with a missing or invalid key return 401 unauthorized.

Quickstart

Send a prompt and receive a response. The model may return text, images, or both.

curl -X POST http://localhost:8000/api/v1/chat \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "draw a red panda astronaut",
    "max_images": 1
  }'

Endpoints

POST /api/v1/chat Generate text and images

Generate chat

Send a prompt. Optionally attach up to four reference images to edit, restyle, or use as visual context.

FieldTypeRequiredDescription
promptstringyesInstruction or question for the model.
imagesstring[]noReference images as data URLs (data:image/png;base64,...). Max 4.
max_imagesintegernoMaximum number of images to return. Default 4, range 0–8.

Editing an image

To edit a photo, convert it to a data URL and include it in the images array. The prompt describes the change.

import base64, requests

with open("photo.jpg", "rb") as f:
    b64 = base64.b64encode(f.read()).decode()

r = requests.post(
    "http://localhost:8000/api/v1/chat",
    headers={"X-API-Key": "YOUR_KEY"},
    json={
        "prompt": "turn this into a watercolor painting",
        "images": [f"data:image/jpeg;base64,{b64}"],
    },
)
print(r.json())
!
Each image must be under 5 MB. The total request body is limited to 16 MB.

Errors

Every error uses the same envelope.

{
  "success": false,
  "error": {
    "code": "validation_error",
    "message": "Field 'prompt' is required"
  }
}
StatusCodeDescription
400invalid_jsonRequest body is not valid JSON.
401unauthorizedMissing or invalid API key.
404not_foundUnknown route.
413payload_too_largeBody exceeds 16 MB.
422validation_errorA field is missing or invalid.
500internal_errorServer-side failure.
